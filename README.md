**Case Study:** PayFlow Nigeria

## Project Overview

This repository contains my individual practical portfolio for MIT8103. It explores the application of database management concepts through a simulated fintech platform, PayFlow Nigeria.

## Portfolio Contents

### Portfolio 1: Database Design and Modelling
Relational database design, tables, relationships, keys and normalisation.

### Portfolio 2: Query Processing and Optimisation
PostgreSQL queries, indexing, execution plans and performance analysis.

### Portfolio 3: Transactions and Concurrency
Transaction processing, COMMIT, ROLLBACK and row-level locking.

### Portfolio 4: NoSQL and Advanced Data Models
MongoDB document modelling, embedded documents, indexing and aggregation.

### Portfolio 5: Distributed and Cloud Database Exercise
Proposed database replication, sharding, availability, consistency and cloud architecture.
